# ExerciciosCSharp

Este repositório contém uma coleção de exercícios em C#, abordando uma variedade de tópicos, desde conceitos básicos, como tipos de dados, estruturas condicionais, métodos e propriedades, até desafios mais avançados.

O objetivo é demonstrar meu aprendizado e evolução na linguagem, por meio de uma prática progressiva. 

1-  Valores em string utilizando diferentes formas de declaração. 

2 - Exibindo no console dois valores numéricos, número inteiro, um número com casas decimais, e o resultado da soma entre eles.

3- Três comparações com bool; uma com maior, menor ou igual e diferente.

4- Três comparações com operadores lógicos com and, or e not;

5 - Operação que gera o valor especial NaN (Not-A-Number), que significa "não é um número", e exibi esse valor no console.

6- Declaração de variável utilizando var (int, string), armazenando um valor dentro da variável.

7- Solicitar idade e nome de um usuário através do console e imprimir os valores.

8- Utilização da função Math para verificar o maior número, o menor número, arredondar um valor que está com casa decimal, e também arredondar um valor para cima independente da primeira casa.
